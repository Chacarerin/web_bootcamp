# 🚀 Sesión 5 Drilling — CSS Avanzado y Diseño Responsivo

Proyecto de mayor envergadura que integra técnicas avanzadas de CSS, incluyendo diseño responsivo mediante media queries y el uso de variables CSS para construir un sistema de diseño coherente.

## 🧠 Contexto Pedagógico y Teórico
El diseño responsivo (Responsive Web Design, RWD) es un paradigma que adapta la interfaz a cualquier tamaño de pantalla sin crear versiones separadas del sitio. Las media queries son la herramienta central: permiten aplicar reglas CSS condicionalmente basándose en características del dispositivo como el ancho de la ventana. El enfoque Mobile-First (diseñar primero para móvil, luego ampliar para escritorio) es la práctica recomendada de la industria.

## ⚙️ Tecnologías y Frameworks Aplicados
* **CSS Media Queries**: Permiten definir puntos de quiebre (breakpoints) donde el layout se reorganiza. Se priorizan breakpoints semánticos (móvil, tablet, escritorio) sobre valores arbitrarios.
* **CSS Variables (`--custom-property`)**: Centralizan los valores del sistema de diseño (colores, tipografía, espaciado) en el selector `:root`, facilitando el mantenimiento y la consistencia visual.
