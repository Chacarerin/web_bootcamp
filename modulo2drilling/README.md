# 🚀 Módulo 2 Drilling — HTML y Formularios Avanzados

[![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat-square&logo=html5&logoColor=white)](https://developer.mozilla.org/html)

Ejercicio de módulo 2 con múltiples páginas HTML, abordando la construcción de formularios avanzados y la navegación entre documentos.

## 🧠 Contexto Pedagógico y Teórico
La gestión de múltiples páginas en un sitio estático introduce conceptos de arquitectura de información: la jerarquía de páginas, la navegación entre ellas y la coherencia visual entre documentos. Estos principios escalan directamente hacia el desarrollo de SPAs con routers como React Router.

## ⚙️ Tecnologías y Frameworks Aplicados
* **HTML Forms Avanzados**: Uso de `<fieldset>`, `<legend>` y tipos de input específicos (`date`, `number`, `select`) para crear formularios accesibles y semánticamente correctos.
