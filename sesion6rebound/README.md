# 🚀 Sesión 6 Rebound — Interactividad y Redirección con JavaScript

[![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat-square&logo=javascript&logoColor=black)](#)

Ejercicio de refuerzo sobre interactividad JavaScript: manipulación de contenido dinámico y navegación entre páginas controlada por script.

## 🧠 Contexto Pedagógico y Teórico
La navegación programática mediante `window.location.href` o `history.pushState()` representa la transición entre el modelo hipermedia estático (HTML puro) y las Single Page Applications (SPAs) modernas, donde el enrutamiento es gestionado por JavaScript en el cliente sin recargar la página completa.

## ⚙️ Tecnologías y Frameworks Aplicados
* **`window.location`**: API nativa del navegador para leer y modificar la URL actual, base de todos los routers de frameworks modernos como React Router o Vue Router.
