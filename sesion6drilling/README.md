# 🚀 Sesión 6 Drilling — Introducción a JavaScript

[![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat-square&logo=javascript&logoColor=black)](#)

Primera exposición práctica al lenguaje JavaScript para la web, cubriendo variables, tipos de datos, funciones y la manipulación básica del DOM.

## 🧠 Contexto Pedagógico y Teórico
JavaScript es el único lenguaje de programación que los navegadores ejecutan de forma nativa, lo que lo hace indispensable para el desarrollo web. Su modelo de ejecución es de un único hilo (single-threaded) con un Event Loop que gestiona operaciones asíncronas, un concepto que distingue a JS de otros lenguajes de propósito general.

## ⚙️ Tecnologías y Frameworks Aplicados
* **JavaScript Vanilla (ES6+)**: Uso de sintaxis moderna (`let`, `const`, arrow functions) en lugar de `var` para aprovechar el alcance de bloque y reducir efectos secundarios inesperados.
* **DOM API**: La interfaz `document` expone el árbol del documento como un objeto manipulable; métodos como `getElementById()` y `querySelector()` permiten seleccionar nodos y modificar su contenido o estilos en tiempo de ejecución.
