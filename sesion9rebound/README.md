# 🚀 Sesión 9 Rebound — Refuerzo de Bootstrap 5

[![Bootstrap](https://img.shields.io/badge/Bootstrap-7952B3?style=flat-square&logo=bootstrap&logoColor=white)](https://getbootstrap.com)

Ejercicio de consolidación del uso de Bootstrap 5 para construir interfaces responsivas con componentes complejos y personalización del tema.

## 🧠 Contexto Pedagógico y Teórico
La personalización de Bootstrap va más allá de sobrescribir clases: el framework expone variables Sass que permiten redefinir colores, tipografía y espaciado antes de la compilación. Comprender este sistema de variables es la diferencia entre un uso básico del framework y un uso profesional que produce interfaces con identidad visual propia.

## ⚙️ Tecnologías y Frameworks Aplicados
* **Bootstrap Utilities**: Las clases de utilidad (`mt-3`, `d-flex`, `text-center`) permiten ajustes de layout y espaciado sin escribir CSS adicional, siguiendo un enfoque híbrido component + utility.
