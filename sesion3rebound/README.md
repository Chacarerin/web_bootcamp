# 🚀 Sesión 3 Rebound — Refuerzo de Estilos CSS

[![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat-square&logo=css3&logoColor=white)](#)

Ejercicio de consolidación de estilos CSS. Aplica las propiedades fundamentales del modelo de cascada y herencia, reforzando selectores, pseudo-clases y el modelo de caja.

## 🧠 Contexto Pedagógico y Teórico
El modelo de cascada de CSS define cómo se resuelven los conflictos de estilos mediante la **especificidad**: un selector de ID supera a uno de clase, que supera a uno de elemento. Comprender este mecanismo es crítico para depurar interfaces complejas y evitar el anti-patrón de abusar de `!important`.

## ⚙️ Tecnologías y Frameworks Aplicados
* **Selectores CSS avanzados**: Uso de selectores de clase, pseudo-clases (`:hover`, `:focus`) y selectores descendentes para aplicar estilos de forma precisa y mantenible.
