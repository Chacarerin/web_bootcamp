# 🚀 Sesión 9 Drilling — Bootstrap 5: Grilla y Componentes

[![Bootstrap](https://img.shields.io/badge/Bootstrap-7952B3?style=flat-square&logo=bootstrap&logoColor=white)](https://getbootstrap.com)

Proyecto de implementación de interfaces responsivas utilizando el sistema de grilla de 12 columnas y el ecosistema de componentes de Bootstrap 5.

## 🧠 Contexto Pedagógico y Teórico
Bootstrap implementa un sistema de grilla basado en Flexbox que divide el viewport en 12 columnas abstractas. Las clases `col-sm-*`, `col-md-*` y `col-lg-*` definen cuántas columnas ocupa un elemento en cada breakpoint, permitiendo layouts adaptativos sin escribir media queries manualmente. Este enfoque de utility-first con componentes predefinidos acelera el prototipado pero requiere comprender CSS subyacente para customizarlo efectivamente.

## ⚙️ Tecnologías y Frameworks Aplicados
* **Bootstrap Grid System**: Sistema de 12 columnas con clases responsivas que eliminan la necesidad de escribir media queries para layouts estándar.
* **Bootstrap Components**: Navbars, cards, modals, alerts y badges como biblioteca de componentes UI listos para producción, con accesibilidad integrada (ARIA attributes).
