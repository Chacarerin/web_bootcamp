# 🚀 Módulo 1 Drilling — Estructura HTML Fundamental

[![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat-square&logo=html5&logoColor=white)](https://developer.mozilla.org/html)

Ejercicio de módulo enfocado en la construcción de la estructura básica de un documento HTML, aplicando etiquetas semánticas y la jerarquía correcta del árbol del DOM.

## 🧠 Contexto Pedagógico y Teórico
El árbol DOM (Document Object Model) es la representación estructural de un documento HTML como un árbol jerárquico de nodos. La correcta aplicación de etiquetas semánticas no solo mejora la legibilidad del código, sino que impacta directamente en la accesibilidad del sitio (lectores de pantalla) y en el posicionamiento en buscadores (SEO).

## ⚙️ Tecnologías y Frameworks Aplicados
* **HTML5 Semántico**: Uso de etiquetas como `<header>`, `<main>`, `<footer>`, `<section>` y `<article>` en lugar de `<div>` genéricos, para aportar significado estructural al contenido.
