# 🚀 Sesión 7 Drilling — JavaScript Avanzado (Evaluación Final)

[![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat-square&logo=javascript&logoColor=black)](#)

Evaluación final del módulo de JavaScript. Proyecto integrador que consolida el dominio de manipulación del DOM, manejo de eventos, estructuras de control y lógica de negocio en el cliente.

## 🧠 Contexto Pedagógico y Teórico
Una evaluación de módulo en programación no solo valida el conocimiento sintáctico, sino la capacidad de descomponer un problema en funciones cohesivas y de bajo acoplamiento. Un código bien estructurado en esta etapa demuestra comprensión del principio de Responsabilidad Única (SRP): cada función hace una sola cosa y la hace bien.

## ⚙️ Tecnologías y Frameworks Aplicados
* **JavaScript ES6+**: Aplicación de closures, callbacks y el scope léxico para construir lógica de aplicación modular y sin efectos secundarios inesperados.
* **Integración HTML + JS**: Separación del comportamiento (`.js`) de la estructura (`.html`) mediante el atributo `defer` o la ubicación estratégica del `<script>` al final del `<body>`.
