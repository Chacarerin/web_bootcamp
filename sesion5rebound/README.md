# 🚀 Sesión 5 Rebound — Refuerzo de Diseño Responsivo

[![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat-square&logo=css3&logoColor=white)](#)

Ejercicio de consolidación del diseño responsivo, reforzando la adaptación de layouts complejos a múltiples tamaños de pantalla con media queries y Flexbox.

## 🧠 Contexto Pedagógico y Teórico
La adaptación responsiva no es solo cambiar tamaños de fuente, sino reorganizar la estructura visual completa. Un menú horizontal de escritorio puede convertirse en un menú hamburguesa en móvil. Esta transformación requiere comprender el flujo del documento HTML y cómo Flexbox y CSS Grid permiten reorganizar el orden visual sin alterar el orden semántico del HTML.

## ⚙️ Tecnologías y Frameworks Aplicados
* **Flexbox + Media Queries combinados**: El patrón de layout responsivo más común: un contenedor Flexbox que cambia su `flex-direction` de `row` a `column` en el breakpoint móvil.
