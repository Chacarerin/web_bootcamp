# 🚀 Sesión 4 Rebound — Layout con Flexbox

[![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat-square&logo=css3&logoColor=white)](#)

Ejercicio de refuerzo sobre el módulo de layout Flexbox, el estándar moderno para construir interfaces unidimensionales en CSS.

## 🧠 Contexto Pedagógico y Teórico
Flexbox (Flexible Box Layout) resolvió los problemas históricos del layout CSS (flotados, `display: inline-block`) al introducir un sistema de alineamiento basado en un eje principal y un eje secundario. Las propiedades `justify-content`, `align-items` y `flex-wrap` permiten crear layouts responsivos complejos con pocas líneas de código.

## ⚙️ Tecnologías y Frameworks Aplicados
* **CSS Flexbox**: Sistema de layout unidimensional que permite distribuir el espacio y alinear elementos dentro de un contenedor de forma predecible, siendo la base de frameworks como Bootstrap Grid.
