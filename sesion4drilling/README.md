# 🚀 Sesión 4 Drilling — Modelo de Caja y Posicionamiento CSS

[![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat-square&logo=css3&logoColor=white)](#)

Ejercicio sobre el modelo de caja (Box Model) de CSS y los esquemas de posicionamiento (static, relative, absolute, fixed), fundamentos del layout web.

## 🧠 Contexto Pedagógico y Teórico
El Box Model define cómo cada elemento HTML ocupa espacio: su contenido, relleno (padding), borde (border) y margen (margin). Comprender la diferencia entre `box-sizing: content-box` y `box-sizing: border-box` es fundamental para crear layouts predecibles. El posicionamiento CSS controla cómo los elementos se ubican en el flujo del documento y en relación con su contexto de posicionamiento.

## ⚙️ Tecnologías y Frameworks Aplicados
* **CSS Box Model**: Manejo explícito de `margin`, `padding`, `border` y `width`/`height` para construir layouts precisos sin herramientas de grilla.
