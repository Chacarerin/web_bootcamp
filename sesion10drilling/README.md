# 🚀 Sesión 10 Drilling — Proyecto Integrado: Aerolínea SKYP

[![Bootstrap](https://img.shields.io/badge/Bootstrap-7952B3?style=flat-square&logo=bootstrap&logoColor=white)](https://getbootstrap.com)
[![jQuery](https://img.shields.io/badge/jQuery-0769AD?style=flat-square&logo=jquery&logoColor=white)](https://jquery.com)

Proyecto integrador de mayor complejidad: implementación de un sitio web completo para la aerolínea ficticia "SKYP". Integra Bootstrap 5, jQuery y CSS personalizado en una interfaz de usuario profesional y responsiva.

## 🧠 Contexto Pedagógico y Teórico
Los proyectos integradores son el método pedagógico más efectivo para consolidar múltiples tecnologías bajo un problema de negocio realista. El sistema de una aerolínea, con sus secciones de planificación de viajes, administración de vuelos y check-in, exige una arquitectura de información clara, una jerarquía visual coherente y una experiencia de usuario fluida, poniendo a prueba el criterio de diseño del desarrollador más allá del conocimiento técnico puro.

## ⚙️ Tecnologías y Frameworks Aplicados
* **Bootstrap 5 Navbar**: Componente de navegación responsivo con `navbar-toggler` para el menú hamburguesa en móvil, implementando el patrón de colapso progresivo.
* **Bootstrap 5 + CDN**: Integración vía CDN para entornos sin sistema de empaquetado (webpack/vite), el método estándar para proyectos estáticos.
* **jQuery + Bootstrap JS**: Integración de la capa de interactividad JavaScript de Bootstrap que depende de jQuery para algunos componentes en versiones anteriores.
