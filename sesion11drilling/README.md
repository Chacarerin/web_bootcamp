Evaluación final del Bootcamp de Desarrollo Web. Proyecto de síntesis que demuestra el dominio integral de las tres tecnologías fundamentales del front-end: HTML, CSS y JavaScript.

## 🧠 Contexto Pedagógico y Teórico
La evaluación final de un bootcamp valora la capacidad de integrar y aplicar todos los conocimientos adquiridos ante un problema de diseño e implementación real. El artefacto entregable (`finalsesion11rubenschnettler.zip`) incluye el proyecto completo, y los archivos de referencia visual (`parteA.png`, `parteB.png`) documentan el diseño objetivo, evidenciando el proceso de traducción de un mockup visual a código funcional.

## ⚙️ Tecnologías y Frameworks Aplicados
* **Stack Web Completo**: Integración armónica de HTML para estructura, CSS para presentación y JS para comportamiento, demostrando el dominio del paradigma de separación de responsabilidades del desarrollo web.
