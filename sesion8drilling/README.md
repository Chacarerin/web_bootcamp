# 🚀 Sesión 8 Drilling — jQuery y Manipulación del DOM

[![jQuery](https://img.shields.io/badge/jQuery-0769AD?style=flat-square&logo=jquery&logoColor=white)](https://jquery.com)

Ejercicio de implementación de interactividad web usando la librería jQuery, la herramienta de manipulación del DOM más utilizada históricamente en la web.

## 🧠 Contexto Pedagógico y Teórico
jQuery abstracte las inconsistencias entre navegadores (cross-browser compatibility) que existían en los estándares del DOM antes de ES6 y la estandarización de los navegadores modernos. Aunque el desarrollo greenfield tiende hacia JavaScript vanilla, comprender jQuery es una habilidad de alto valor porque un enorme porcentaje del código web existente (incluyendo WordPress y sistemas legacy corporativos) depende de él.

## ⚙️ Tecnologías y Frameworks Aplicados
* **jQuery DOM Selection**: El selector `$()` es una abstracción sobre `querySelector` que soporta la sintaxis CSS completa para seleccionar elementos, simplificando drásticamente el código.
* **jQuery Events (`.on()`, `.click()`)**: Sistema de eventos simplificado que gestiona automáticamente la compatibilidad cross-browser.
