# 🚀 Sesión 7 Rebound — Refuerzo de JavaScript Avanzado

[![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat-square&logo=javascript&logoColor=black)](#)

Ejercicio de consolidación de conceptos avanzados de JavaScript: arrays, objetos, iteración y lógica condicional aplicados a casos de uso reales.

## 🧠 Contexto Pedagógico y Teórico
Los métodos de array de alto orden (`map`, `filter`, `reduce`) son la piedra angular de la programación funcional en JavaScript. Su uso frente a los bucles `for` tradicionales produce código más declarativo (describe el "qué" en lugar del "cómo"), más predecible y más fácil de testear unitariamente.

## ⚙️ Tecnologías y Frameworks Aplicados
* **Array Methods (ES6)**: `forEach`, `map`, `filter` y `find` como alternativas idiomáticas a los bucles imperativos, facilitando la lectura y el mantenimiento del código.
