# 🚀 Sesión 8 Rebound — Refuerzo de jQuery

[![jQuery](https://img.shields.io/badge/jQuery-0769AD?style=flat-square&logo=jquery&logoColor=white)](https://jquery.com)

Ejercicio de consolidación de jQuery, reforzando animaciones, efectos visuales y manipulación dinámica del contenido del DOM.

## 🧠 Contexto Pedagógico y Teórico
Los métodos de animación de jQuery (`.fadeIn()`, `.slideToggle()`, `.animate()`) son abstracciones sobre las transiciones CSS y la API de Web Animations, que simplifican la creación de efectos visuales interactivos. Comprender qué ocurre "debajo del capó" (manipulación de estilos inline y requestAnimationFrame) es clave para optimizar el rendimiento de la interfaz.

## ⚙️ Tecnologías y Frameworks Aplicados
* **jQuery Effects & Animation**: Métodos de alto nivel para transiciones que mantienen el código legible y compatible con navegadores que no soportan transiciones CSS3 avanzadas.
