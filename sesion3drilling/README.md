# 🚀 Sesión 3 Drilling — Sistema de Botones CSS

[![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat-square&logo=css3&logoColor=white)](#)

Ejercicio de diseño de un sistema de botones CSS con clases semánticas (primario, secundario, éxito, peligro), aplicando el principio de diseño basado en componentes reutilizables.

## 🧠 Contexto Pedagógico y Teórico
Un sistema de botones bien diseñado es la base de cualquier guía de estilos (Design System). Cada clase semántica comunica intención: `.primary-btn` para acciones principales, `.danger-btn` para acciones destructivas. Este enfoque de nomenclatura por función (no por apariencia) facilita el mantenimiento del código y la consistencia visual.

## ⚙️ Tecnologías y Frameworks Aplicados
* **CSS3 con BEM-like naming**: Las clases de botón siguen una convención semántica que mejora la legibilidad del HTML y permite escalar el sistema de diseño sin conflictos de especificidad.
