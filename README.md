Repositorio integral del Bootcamp de Desarrollo Web Front-End. Documenta la progresión pedagógica desde la estructura semántica del documento HTML hasta el desarrollo de interfaces dinámicas con JavaScript y sistemas de componentes con Bootstrap.

## 🧠 Contexto Pedagógico y Teórico
El desarrollo web front-end moderno exige el dominio de tres lenguajes complementarios que operan en capas distintas: HTML define la **estructura semántica** del contenido, CSS gestiona la **presentación visual** y el diseño responsivo, y JavaScript agrega **comportamiento dinámico** en el lado del cliente. Este bootcamp recorre sistemáticamente cada capa, construyendo una comprensión integral del ecosistema web.

## ⚙️ Tecnologías y Frameworks Aplicados
* **HTML5**: Estructura semántica de documentos con etiquetas apropiadas para mejorar accesibilidad y SEO.
* **CSS3**: Cascada de estilos, modelo de caja, Flexbox y diseño responsivo con media queries.
* **JavaScript Vanilla**: Manipulación del DOM, gestión de eventos y lógica de cliente sin dependencias.
* **jQuery**: Librería de abstracción del DOM que simplifica la selección de elementos y el manejo de eventos, ampliamente utilizada en codebases legacy de la industria.
* **Bootstrap 5**: Sistema de componentes y grilla CSS que acelera el desarrollo de interfaces responsivas, siendo el framework front-end más utilizado a nivel mundial.
