# 🚀 Sesión 2 Rebound — Formularios HTML y Redirección

[![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat-square&logo=html5&logoColor=white)](https://developer.mozilla.org/html)

Ejercicio de refuerzo sobre la construcción de formularios HTML y la navegación entre páginas mediante redirección.

## 🧠 Contexto Pedagógico y Teórico
Los formularios HTML son el mecanismo primario de entrada de datos del usuario en la web. Este ejercicio consolida el conocimiento de los atributos fundamentales: el atributo `action` define el endpoint destino de los datos, `method` define el verbo HTTP (GET o POST), y los distintos tipos de `<input>` (`text`, `email`, `submit`) controlan la naturaleza de los datos capturados. La redirección entre páginas mediante `<a href>` demuestra la navegación sin JavaScript como base del modelo hipermedia de la web.

## ⚙️ Tecnologías y Frameworks Aplicados
* **HTML5 Forms API**: Uso de etiquetas semánticas `<form>`, `<label>` e `<input>` siguiendo las mejores prácticas de accesibilidad, donde cada campo tiene su `<label>` asociado mediante el atributo `for`.

## 🛠️ Desglose Técnico (El "Cómo")
* **`formsesion2.html`**: Formulario principal con campos de entrada tipados y botón de envío.
* **`redireccion.html`**: Página destino que valida el flujo de navegación y redirección entre documentos HTML.
